

# Carta Blanka Website

## Project Description

Carta Blanka Website is a responsive landing page created for an indie alternative rock band. The site showcases the band's identity, upcoming events, members, and media content. It is designed to provide a modern and immersive user experience using visual elements and smooth navigation.

## Technologies Used

* HTML5
* CSS3
* JavaScript (for mobile navigation menu)

## How to Run the Project Locally

1. Download or clone this repository.
2. Open the project folder.
3. Locate the `index.html` file.
4. Open it in your web browser (double click or right-click → open with browser).

No additional dependencies or installations are required.

## Features

* Responsive design for mobile and desktop devices
* Interactive navigation menu for small screens
* Sections for band information, events, members, and media
* Image galleries and external links (Instagram, Spotify, YouTube)
